다희와 준희의 문해력 성장 교실 · V2.1

화면 파일을 연결해 주세요

이 주소는 교실 화면에 사용하는 그림과 글꼴을 제공합니다. 학생과 선생님은 설정을 마친 Apps Script 웹 앱 주소로 접속합니다.

1. 파일 주소 복사하기

Apps Script의 프로젝트 설정 → 스크립트 속성에서 ASSET_BASE_URL을 추가하고 위 주소를 붙여넣으세요.

2. 업로드한 파일 점검하기

그림 3개와 글꼴 5개를 읽어 파일 크기와 SHA-256이 원본과 같은지 확인합니다. 약 6.6MB를 읽으며 학생 기록에는 접근하지 않습니다.

    3. 교실 열기

    Apps Script에 Code.gs, Student.html, Admin.html을 교체한 뒤, 웹 앱으로 배포해 주세요. 이미 배포했다면 새 버전을 적용합니다.

    • 학생용: 배포한 웹 앱의 /exec 주소
    • 관리자용: 같은 주소 끝에 ?page=admin 추가

    이 파일 점검은 공개 화면 파일을 확인합니다. 실제 학생 저장과 관리자 조회는 Apps Script 배포 주소에서 확인해 주세요.
